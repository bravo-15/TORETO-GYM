# Backend Context

## Descripción General
Backend del sistema TORETO GYM desarrollado con Node.js y Express.

## Stack Tecnológico
- Node.js
- Express
- MySQL
- JWT
- bcryptjs
- dotenv

## Arquitectura Backend
API REST organizada en rutas, controladores y middlewares.

## Estructura de Carpetas
- controllers/
- routes/
- middlewares/
- config/

## Flujo General
Request → Route → Controller → MySQL → Response

## Seguridad
Autenticación JWT y control de roles.

## Base de Datos
Conexión mediante mysql2/promise.
