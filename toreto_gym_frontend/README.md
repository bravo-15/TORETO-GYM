# Frontend TORETO GYM

Frontend creado con React + Vite para conectarse al backend de TORETO GYM.

## Instalación

```bash
npm install
npm run dev
```

## Configuración

El archivo `.env` usa:

```env
VITE_API_URL=http://localhost:3001/api
```

Si tu backend usa otro puerto, cambia ese valor.
